# Перелёт Земля — Каллисто

## Цель игры
Учебный симулятор космического полёта. Игроку нужно запустить аппарат с Земли и, используя гравитационный манёвр у Юпитера, попасть в отмеченную область около Каллисто.

## Правила и управление
* **Настройка импульса:** Игрок задаёт силу (0-100%) и направление (0-359°) с помощью ползунков.
* **Запуск:** Нажатие кнопки «Запуск» (или Enter/Пробел на ПК).
* **Коррекция клавиатурой:** На компьютере ползунки можно крутить стрелками ←/→ (угол) и ↑/↓ (сила).
* **Завершение:** Успех при попадании в зелёный пунктирный круг. Провал при столкновении с планетами или уходе за экран. Кнопка «Заново» сбрасывает игру.

## Как запустить
1. Скачайте файлы `index.html`, `style.css`, `script.js` в одну папку.
2. Откройте `index.html` в любом современном браузере.
3. Или откройте игру по ссылке на GitHub Pages: [ссылка на вашу игру].

## Ограничения
Это учебная упрощённая модель. Массы планет и расстояния подогнаны для играбельности, а не для реальных астрономических расчётов. Физика рассчитывается методом Эйлера, без учёта сложных орбитальных механик.
